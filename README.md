**ProxPool** is a self-hosted multi-proxy orchestration platform that runs **100+ passive income, bandwidth-sharing, and DePIN services** on your own servers or residential proxy pools. Using isolated `tun2socks` network namespaces in Docker, ProxPool routes each worker container through its own dedicated Residential or Datacenter IP—allowing you to scale 20x, 50x, or 100x nodes from a single machine without IP conflicts.

## 🚀 Quick Start Guide

### Option A: 1-Command VPS Automated Installer (Ubuntu / Debian)
Deploy Docker Engine, `tun2socks` kernel routing, and the **ProxPool Web Command Center (Port 8899)** with a single command:
```bash
curl -sSL https://raw.githubusercontent.com/AbyanZainZ/ProxPool-/main/deploy_vps.sh | sudo bash
```
Once complete, open **`http://YOUR_VPS_IP:8899`** in your browser to:
- Edit all `.env` platform tokens & credentials live from the Web GUI
- Paste your `socks5://` or `http://` proxies into the **Multi-Proxy Pool** editor
- Click **Start Single Host (VPS IP)** or **Generate & Start Multi-Proxy Farm**
- Monitor real-time CPU, RAM, Network Traffic, Docker Container states, and **EarnApp Claim Links**

---

### Option B: Manual Clone & Local / Windows Setup

#### 1. Clone the Repository
```bash
git clone https://github.com/AbyanZainZ/ProxPool-.git
cd ProxPool-
```

#### 2. Launch the Web Command Center Dashboard (Port 8899)
```bash
# Windows (1-Click Launcher)
run_dashboard.bat

# Linux / macOS
pip install -r requirements.txt
python -m uvicorn app:app --host 0.0.0.0 --port 8899
```
Then open **`http://127.0.0.1:8899`** in your browser.

#### 3. Or Run via CLI Scripts
1. Copy `.env.example` to `.env` and fill in your account tokens/emails for the platforms you registered above.
2. Add your proxies (`socks5://user:pass@ip:port` or `http://user:pass@ip:port`) to `proxies.txt`.
3. Launch containers:
   * **Single Host Mode (Direct VPS/Home IP)**:
     ```bash
     # Windows
     start_single.bat

     # Linux / macOS
     bash start_single.sh
     ```
   * **Multi-Proxy Mode (Isolated Proxy Clusters via `tun2socks`)**:
     ```bash
     # Windows
     start_multiproxy.bat

     # Linux / macOS
     bash start_multiproxy.sh
     ```
4. View all generated EarnApp claim links:
   ```bash
   python check_status.py
   ```
